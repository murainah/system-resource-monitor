# Changelog

## 0.4.0

- Added Ruff linting and formatting checks, with automatic checks for staged Python files through pre-commit.
- Added configurable DEBUG, INFO, WARNING, ERROR, and CRITICAL logging for resource collection, CSV recording, high usage, and failures.
- Expanded the pytest suite to cover mocked resource measurements, CSV input and output, CLI commands, and continuous monitoring.
- Restored the MIT License and included it in the built packages.
- Streamlined the README and added a generated Python API reference and a beginner tutorial.
